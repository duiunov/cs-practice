
Git — это программа для отслеживания изменений в коде на вашем компьютере, а GitHub — это платформа в интернете для хранения этого кода и совместной работы

git status Показывает общую сводку состояния рабочей директории
git diff Показывает детальную разницу (построчно) между рабочей директорией (вашими текущими файлами) и индексом (staging area)
git diff --staged (также пишется как --cached)Показывает детальную разницу между индексом (тем, что уже подготовлено через git add) и последним коммитом в текущей ветке.
